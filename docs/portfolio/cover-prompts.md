# Portfolio cover prompt set

The four covers were created with the built-in image generation workflow. Each
prompt used the real product screenshot listed below as a reference image.

## Shared direction

- Use case: `ads-marketing`
- Asset: platform-neutral portfolio project cover, landscape 4:3
- Style: premium, modern software-engineering case study; crisp, minimal, and
  credible rather than futuristic
- Backdrop: deep navy technical surface with restrained emerald accents
- Composition: real application screen in a clean desktop-window presentation
- Constraints: preserve the recognizable product UI; no invented functionality,
  fake metrics, people, trucks, extra logos, or watermarks

## Full application

- Reference: `docs/images/dashboard.png`
- Primary text: `ETS2 EU DIGITAL TACHOGRAPH`
- Subtitle: `FULL DESKTOP APPLICATION`
- Additional visual direction: subtle telemetry grid and chart lines; screenshot
  occupies the lower-right portion with clear title space.

## Journey Planner

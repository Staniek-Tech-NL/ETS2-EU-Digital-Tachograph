# Security Policy / Polityka bezpieczeństwa

## Supported version / Wspierana wersja

Security reports are accepted for the latest published version. During M8 the
target version is `0.1.0-beta.12`.

Zgłoszenia bezpieczeństwa są przyjmowane dla najnowszej opublikowanej wersji.
W trakcie M8 wersją docelową jest `0.1.0-beta.12`.

## Reporting a vulnerability / Zgłaszanie podatności

Use GitHub **Private vulnerability reporting** from the repository Security
tab. Do not disclose a suspected vulnerability in a public Issue or
Discussion. Include the affected version, reproduction steps, impact, and any
safe supporting material. Do not attach real credentials or private user data.

Użyj funkcji GitHub **Private vulnerability reporting** w zakładce Security
repozytorium. Nie ujawniaj podejrzewanej podatności w publicznym Issue ani
Discussion. Podaj wersję, kroki reprodukcji, wpływ i bezpieczne materiały
pomocnicze. Nie dołączaj prawdziwych poświadczeń ani prywatnych danych.

Reports are handled on a best-effort basis without an SLA. Acknowledgement,
investigation, and coordinated disclosure timing depend on severity and the
maintainer's availability.

Zgłoszenia są obsługiwane w modelu best effort, bez SLA. Termin potwierdzenia,
analizy i skoordynowanego ujawnienia zależy od wagi problemu i dostępności
opiekuna projektu.

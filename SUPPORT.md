# Support / Wsparcie

## Polski

Projekt jest rozwijany niezależnie. Zgłoszenia są analizowane w modelu
**best effort**. Nie jest gwarantowany czas odpowiedzi ani termin wdrożenia
poprawki. Błędy P0/P1 otrzymują priorytet przed propozycjami nowych funkcji.

- Błędy zgłaszaj przez GitHub Issues, korzystając z formularza **Bug report**.
- Dołącz raport diagnostyczny ZIP wygenerowany przez aplikację, jeśli nie
  zawiera danych, których nie chcesz publikować.
- Pytania, pomoc użytkową i pomysły kieruj do GitHub Discussions.
- Nie jest świadczone wsparcie przez prywatne wiadomości.

Przed zgłoszeniem zapoznaj się z `KNOWN_ISSUES.md`. Nie publikuj kluczy, tokenów,
poświadczeń ani innych danych wrażliwych.

## English

This project is maintained independently on a **best-effort** basis. No
response time or fix delivery date is guaranteed. P0/P1 defects take priority
over feature requests.

- Report bugs through GitHub Issues using the **Bug report** form.
- Attach the diagnostic ZIP generated by the application when it contains no
  data you do not want to publish.
- Use GitHub Discussions for questions, user help, and ideas.
- Support is not provided through private messages.

Check `KNOWN_ISSUES.md` before reporting a problem. Never publish keys, tokens,
credentials, or other sensitive information.

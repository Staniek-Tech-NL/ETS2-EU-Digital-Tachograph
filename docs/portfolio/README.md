# Portfolio case studies

ETS2 EU Digital Tachograph is one real application presented through four
different engineering perspectives. The module case studies below are not
standalone products or separate repositories; each one documents a focused
part of the same desktop application.

## Case studies

1. [Full application](../../README.md) — native telemetry, desktop product,
   persistence, rules, reporting, testing, and release engineering.
2. [Journey Planner](journey-planner.md) — constraint-based driving and rest
   planning.
3. [Activity Gap Reconstruction](activity-gap-reconstruction.md) — manual data
   reconstruction, validation, and transactional persistence.
4. [Reporting & Analytics](reporting-analytics.md) — aggregation, completeness
   checks, and multi-format exports.
